# How to update the lab website

*No coding needed. Changes go live on the website about a minute after you save.*

## Logging in

1. Go to **https://app.pagescms.org**
2. Click **Sign in with GitHub** and use the lab account (`attentivelab`).
3. Pick the website repository. The menu on the left lists everything you can edit.

## The menu, and what each item changes

| Menu item | What it controls |
|---|---|
| **Publications** | The Publications page (list + featured paper) |
| **Homepage highlights (carousel)** | The rotating papers at the top of the homepage |
| **Lab members** | The Lab members page |
| **Research topics** | The four cards on the homepage AND the Research page |
| **Studies (Participate page)** | The recruitment ads on the Participate page |
| **Collaborators** | The Collaborations page |
| **News** | The News page |
| **Homepage text** | All the editable text on the homepage |

## Common tasks

### A new paper is published
1. Open **Publications** → **Add entry**.
2. Fill in title, authors (exactly as they should appear), year, journal.
3. Upload the PDF in the *PDF of the paper* field.
4. **Save.** It appears on the Publications page automatically, under its year.

### Put a new paper in the homepage carousel
1. Open **Homepage highlights** → **Add entry**.
2. Write the research question (short, punchy — it is displayed very large).
3. Upload the paper's figure as the image.
4. In *Button link*, paste the PDF address, e.g. `/pdfs/MyPaper_2027.pdf`
   (upload the PDF under **Publications** first — the address is `/pdfs/` + the file name).
5. Set *Slide order* (1 = shown first). **Save.**

### Someone joins the lab
**Lab members** → **Add entry** → name, role from the dropdown, upload a portrait photo
(portrait orientation looks best), set the display order. **Save.**

### Someone leaves the lab
Open their entry → switch **Former member** on. They move to the Alumni list.
To remove them entirely, delete the entry instead.

### Change a study on the Participate page
**Studies** → open the study → edit text, duration, or upload a new image. **Save.**
To stop recruiting for a study, delete its entry.

### Change homepage text or the team photo
**Homepage text** → edit any field → **Save.**

## Good to know

- **Images**: photos of people look best in portrait orientation; paper figures and
  study images in landscape. Anything reasonable works — the site crops sensibly.
- **"Failed to upload file: 413"** means the image is too big (limit ≈ 3 MB —
  photos straight from a phone often exceed it). Shrink it first: open the photo
  in Preview → File → Export → lower the quality slider → save, then upload that.
  PDFs of papers are rarely affected.
- **Saving is publishing.** Every save updates the live site (~1 minute).
- **Nothing is ever lost.** Every change is recorded; any mistake can be rolled back —
  ask, and any version can be restored.
- If a save is rejected with an error message, a required field is probably empty —
  the message says which one.
